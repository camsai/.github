# Governance

CAMSAI's governance documents are maintained in
**[camsai/governance](https://github.com/camsai/governance)**, which is
authoritative. This file is a pointer so that every CAMSAI repository resolves
to the same answer.

| Document | |
| --- | --- |
| [Charter](https://github.com/camsai/governance/blob/main/CHARTER.md) | Mission, scope, principles, membership, projects, affiliations, amendments |
| [Governance](https://github.com/camsai/governance/blob/main/GOVERNANCE.md) | Steering Committee, decision rules, project intake and lifecycle |
| [Steering Committee](https://github.com/camsai/governance/blob/main/STEERING.md) | Current roster of seats |
| [Name and marks](https://github.com/camsai/governance/blob/main/TRADEMARKS.md) | Custody of the CAMSAI name, marks, and domain, and permitted uses |
| [Code of Conduct](https://github.com/camsai/governance/blob/main/CODE_OF_CONDUCT.md) | Expected conduct, and how to report a concern |

Each ratified version is published as a consolidated PDF under
[releases](https://github.com/camsai/governance/releases).

CAMSAI is not yet incorporated; see the Charter, section 8.
